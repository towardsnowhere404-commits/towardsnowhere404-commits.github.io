Privacy Policy

Last updated: November 17, 2026

Nowhere Publisher ("the tool") is a personal application operated by an individual developer to upload videos to YouTube channels that the developer owns. This policy explains what data the tool accesses and how it is handled.

YouTube API Services

The tool uses YouTube API Services. By using the tool, you agree to the YouTube Terms of Service. Google's handling of data is governed by the Google Privacy Policy.

Data accessed

When a channel is connected, the tool receives an OAuth token from Google that allows it to upload videos and to read the connected channel's own videos and statistics. The tool uses this access only to (1) upload videos and their metadata to that channel and (2) read view, watch-time and impression statistics of that channel's own videos for an internal report. The tool does not access data of any other user or channel.

Storage

OAuth tokens and statistics are stored only on the developer's own computer. Nothing is stored on external servers, and statistics older than 30 days are refreshed or deleted in line with the YouTube API Services policies.

Sharing

The tool does not sell, share or transfer any data to third parties, and it does not use cookies, analytics or advertising.

Revoking access and deletion

Access can be revoked at any time on the Google Account security settings page. Upon revocation, or upon request to the contact below, all stored tokens and data are deleted within 7 days.
